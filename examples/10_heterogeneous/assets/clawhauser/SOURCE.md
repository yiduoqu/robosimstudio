# Clawhauser source asset

These files are copied byte-for-byte from the user's local Newton handoff at
`newton/outputs/newton_handoff_20261021/assets/clawhauser/` for a reproducible
RoboSimStudio scene. They are source data, not generated by this example.

- `final_mesh.mesh`: one connected Medit tetrahedral mesh, 1,840 vertices and
  6,850 tetrahedra. The original file winding is retained on disk; the loader
  corrects negative winding in memory without reordering tetrahedra.
- `heterogeneous_params.npz`: source tet labels, Young's modulus, Poisson ratio,
  and density. IDs 0, 1, 2 mean plush tail, plush body, and flexible loop/clasp.
- `inferred_params.json`: source part names, material estimates, and friction.
- `appearance/`: source visual mesh, albedo, and vertex/face binding to the
  physics mesh. The scene passes part colors to Newton's physics boundary, but
  the tiled overview does not reliably distinguish them; the per-tet labels
  remain the authoritative part representation.

The loop is an elastomer estimate and part of the same FEM volume. This data
does not describe a separate metal ring or a rigid core.

The scene checks SHA-256 digests for the mesh, per-tet parameters, material JSON,
and visual-to-physics binding before building. This guards the correspondence
between tetrahedra and material rows, which the original NPZ does not encode:

- `final_mesh.mesh`: `df3d1505d96d36fbfa76291e7ab94269a30500ba5e4b87516d0bf8f57f0c6458`
- `heterogeneous_params.npz`: `7cfc8ca3cc7c08d261aa90b08832230801fec1ac62848d0e9239d9e2f318e8c6`
- `inferred_params.json`: `45aacd698f2b38a6fd8bf13b46cc9c33497fc90c6c1bdf088ed12d915ec3d992`
- `appearance/visual_to_physics.npz`: `4b015d1141794211e4e2c6e2b39fadef6762a73ffe2d76b921e47d5676f3d6c4`
